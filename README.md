# P18 Marketplace

A Claude Code plugin marketplace for real, tested geometric data-addressing
tools — real byte-pair compression and an offline tiered-confidence
response cache, both built and verified against real files and a real
local LLM.

## Install

```
/plugin marketplace add ras2045/p18-tools-marketplace
/plugin install p18-tools@p18-marketplace
```

## What's in it

See [`plugins/p18-tools/README.md`](plugins/p18-tools/README.md) for the
real, tested capabilities and requirements.
